# מפרט וחוקי שפת העיצוב "זֶן 2.0" (Zen 2.0 Design System)
**מדריך ארכיטקטוני רשמי למפתחים ולסוכני AI אוטונומיים**  
*Liquid Glass, כרטיסים טקטיליים אטומים (100% Opaque Slate), כפתורים חלולים, וגיאומטריה מלבנית מרוסנת*

---

## 1. תקציר מנהלים ותפיסת היסוד

שפת העיצוב **זֶן 2.0 (Zen Design System)** היא שילוב הנדסי מוקפד בין שפת הזכוכית הנוזלית של Apple (visionOS/macOS), סקאלת הסלייט המונוכרומטית של Radix UI, ואיפוק צורני מבוסס כפתורים חלולים. השפה הותאמה במיוחד לאפליקציות לימודיות, לוחות בקרה ומערכות שדורשות פוקוס קוגניטיבי גבוה, קריאות עברית מושלמת, וחוויית מובייל מהירה וללא פשרות.

### שלושת עמודי התווך
1. **זכוכית נוזלית מיועדת רק לאלמנטים צפים (Overlays Only)**: טשטוש הרקע האופטי (`blur(28px)`) ופסי האור הספקולריים מיועדים אך ורק לסרגל העליון, מגירות צפות וחלונות מודאליים.
2. **תוכן חי על גבי כרטיסים טקטיליים אטומים (100% Opaque)**: לעולם אין לשים זכוכית נוזלית שקופה על גבי זכוכית נוזלית שקופה. כל מיכלי התוכן אטומים לחלוטין (`#ffffff` במצב בהיר, `#15161c` במצב כהה) עם מסגרות סלייט דקיקות וצל מיקרוסקופי.
3. **גיאומטריה מלבנית מרוסנת (חוק ה-Anti-Bubble)**: צורות קפסולה ובועה מעוגלות מדי (`rounded-full`, `border-radius: 9999px`) נאסרו לשימוש באלמנטים פונקציונליים. המערכת מחייבת סולם רדיוסים מלבני של 4px–8px.

---

## 2. שבעת חוקי הברזל (הנחיות מחייבות למפתחים ולסוכני בינה מלאכותית)

כל מפתח או סוכן AI שעושה שימוש בתבנית זו **חייב לציית בקפדנות** לשבעת הכללים הללו. אי-עמידה בהם מהווה רגרסיה ארכיטקטונית מיידית.

### חוק 1: איסור קפסולות וסולם גיאומטריה מלבני (Anti-Bubble)
* **איסור**: אסור לחלוטין להשתמש ב-`rounded-full` או `border-radius: 9999px` על תגיות, כפתורים, כרטיסים, בקרי מקטעים או שדות קלט. צורות קפסולה גורמות לממשק להיראות מלאכותי/ילדותי ומקצצות אותיות סופיות בעברית.
* **סולם הרדיוסים המחייב**:
  | טוקן | ערך | מחלקת Tailwind | שימוש מותר בלבד |
  | :--- | :--- | :--- | :--- |
  | `--radius-badge` | `4px` | `rounded` | תגיות סטטוס, שבבי מטא-דאטה, תגיות מסלול |
  | `--radius-item` | `4px` | `rounded` | שבב פעיל בבקר מקטעים, פריטי תפריט |
  | `--radius-btn` | `6px` | `rounded-md` | כפתורי בסיס חלולים, כפתורי פעולה ראשיים |
  | `--radius-input` | `8px` | `rounded-lg` | שדות קלט, תפריטי בחירה, שדות חיפוש |
  | `--radius-card` | `8px` | `rounded-lg` | כרטיסי תוכן סטנדרטיים, תחנות עבודה |
  | `--radius-container`| `10px`| `rounded-lg` / `rounded-xl` | מיכלי מקטעים, מסגרות קבוצתיות |
  | `--radius-hero` | `12px`| `rounded-xl` | כרטיס פיקוד עליון (Command Hero), כרטיס Spotlight |

### חוק 2: מצב בהיר כברירת מחדל ואפשרות למצב כהה
* **חוק**: **מצב בהיר (Light Mode)** הוא ברירת המחדל הקבועה ב-`:root`. מצב כהה מופעל כשכבת עקיפה תחת `html.dark` (או מחלקת `.dark`).
* **אחידות שמות הטוקנים**: שני המצבים חולקים בדיוק את אותם שמות משתנים. בקוד הרכיבים אין צורך לשכפל קלאסים עם `dark:`.
* **ערכי בסיס**:
  * מצב בהיר: רקע `#f8fafc` (אלבסטר חם ונקי), כרטיסים `#ffffff`, טקסט ראשי `#0f172a`, מסגרות `#e2e8f0`.
  * מצב כהה: רקע `#0c0d10` (Cinema Slate), כרטיסים `#15161c`, טקסט ראשי `#ffffff`, מסגרות `rgba(255,255,255,0.10)`.

### חוק 3: פלטת הבסיס הרשמית — Champagne Gold
* **ברירת המחדל של המערכת**: הפלטה הראשית הנבחרת היא **Champagne Gold**.
  * מצב בהיר: בסיס `#ca8a04`, ריחוף `#a16207`, שטיפה `rgba(202, 138, 4, 0.10)`, מסגרת `rgba(202, 138, 4, 0.35)`.
  * מצב כהה: בסיס `#eab308`, ריחוף `#facc15`, שטיפה `rgba(234, 179, 8, 0.15)`, מסגרת `rgba(234, 179, 8, 0.42)`.
* פלטות משניות נתמכות דרך תכונת `data-theme`: `matte-amber`, `nordic-ice`, `emerald-sanctuary`.

### חוק 4: טיפוגרפיה בעברית ואיסור קיטום טקסטים (Anti-Truncation)
* **חוק**: אסור לחלוטין להשתמש ב-`truncate`, `line-clamp-1` או `line-clamp-2` על כותרות לימודיות, הסברים, או דרגות תלמידים.
* **הסבר פדגוגי**: בעברית, קיטום משפטים עם שלוש נקודות (`...`) פוגע בהבנה. אותיות עבריות ואותיות סופיות (ך, ף, ץ, ן, ם) דורשות מרווח נשימה.
* **יישום מחייב**: שימוש בגלישת שורות טבעית (`break-words`), גובה שורה מרווח (`leading-relaxed` או `leading-snug`).
* **ריפוד תגיות**: תגית תכלול לפחות `px-2 py-0.5` כדי למנוע מרדיוס הפינה לנגוס באותיות.

### חוק 5: כפתורים חלולים בלבד (Hollow Buttons)
* **חוק**: כל הכפתורים הם **כפתורי זכוכית חלולים** עם טשטוש עדין, מסגרת סלייט דקיקה והרמה קלה בלחיצה/ריחוף. אין בלוקים כחולים אטומים או זוהר ניאון מלאכותי.
  * כפתור בסיס (`.btn-hollow`): שטיפה ניטרלית, מסגרת סלייט 1px, רדיוס 6px.
  * כפתור ראשי (`.btn-hollow-primary`): סלייט עמוק או קו אור עליון ספקולרי עם הארה בריחוף.

### חוק 6: עמידות במובייל ואייפון (iOS Safari Hardening)
* **חוק 1 (גודל קלט 16px)**: כל שדה `<input>` ו-`<select>` חייב לקבל `font-size: 16px` במסכים מתחת ל-768px כדי למנוע את הזום האוטומטי המעיק של ספארי באייפון בעת פוקוס.
* **חוק 2 (אפס גלישה ב-375px)**: הסרגל העליון יציג שבב קומפקטי במובייל ולא סרגלי מעבר רחבים. הרוחב המינימלי הנתמך הוא 375px (iPhone SE). גלילה אופקית אסורה בהחלט (`overflow-x: hidden`).
* **חוק 3 (שולי ביטחון)**: סרגלים עליונים ותחתוניים חייבים להשתמש ב-`env(safe-area-inset-top)` וב-`env(safe-area-inset-bottom)`.

### חוק 7: משמעת חזותית ואייקונים וקטוריים בלבד
* **חוק**: שימוש בלעדי באייקוני קו וקטוריים מונוכרומטיים (Lucide). **אסור בהחלט להשתמש באימוג'ים בתוך כפתורים, לשוניות, כותרות או סרגלי ניווט**.

## 3. מבנה קבצי החבילה להעתקה (`design-system/`)

```
design-system/
├── tokens.css             # משתני CSS עצמאיים למצב בהיר וכהה (עם Champagne Gold כברירת מחדל)
├── components.css         # כל מחלקות הרכיבים (.card-tactile, .btn-hollow, .segmented-glass וכו')
├── tailwind.preset.js     # קובץ Preset מוכן לחיבור מיידי ל-Tailwind CSS
├── templates/             # רכיבי React מוכנים לשימוש מיידי
│   ├── Header.jsx         # סרגל זכוכית נוזלית עליון מותאם מובייל
│   ├── TactileCard.jsx    # כרטיס תוכן טקטילי 100% אטום
│   ├── HollowButton.jsx   # כפתורים חלולים תקניים
│   ├── SegmentedControl.jsx # בקר מקטעים ספקולרי
│   ├── Badge.jsx          # תגית מלבנית 4px שלא מקצצת עברית
│   └── ThemeToggle.jsx    # מתג החלפה מהיר בין מצב בהיר לכהה
├── demo.html              # דף הדגמה חי ועצמאי בלחיצה כפולה בכל דפדפן
├── SPECIFICATION.md       # מפרט טכני מלא באנגלית לסוכני AI ומפתחים
└── README.md              # מדריך התחלה מהירה (Quickstart)
```

## 4. צעדי הטמעה מהירים בכל פרויקט חדש

1. **העתקת התיקייה**: מעתיקים את התיקייה `design-system/` אל תוך הפרויקט החדש.
2. **ייבוא סגנונות**: בקובץ ה-CSS הראשי (למשל `index.css`):
   ```css
   @import './design-system/tokens.css';
   @import './design-system/components.css';
   ```
3. **חיבור ל-Tailwind (אם רלוונטי)**: בקובץ `tailwind.config.js` מוסיפים:
   ```javascript
   presets: [require('./design-system/tailwind.preset.js')]
   ```
4. **שימוש ברכיבים**: משתמשים ישירות ברכיבים מתוך `templates/` או בקלאסים הסטנדרטיים.
