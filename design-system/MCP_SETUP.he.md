# מדריך גילוי, משיכה והגדרת שרתי MCP (Apple HIG ו-Playwright)
*כיצד פרויקט המטרה מזהה, מושך ומגדיר את שרת ה-MCP באופן אוטונומי*

---

## 1. מאיפה פרויקט המטרה יודע לקחת את ה-MCP של Apple HIG?

שרת ה-MCP של **Apple Human Interface Guidelines (HIG)** הוא חבילת קוד פתוח רשמית ומפורסמת במאגר ה-npm הציבורי:
- **שם החבילה ב-npm**: `apple-hig-mcp`
- **מאגר GitHub**: `https://github.com/tmaasen/apple-hig-mcp`
- **פקודת הפעלה**: `apple-hig-mcp` (או ישירות ללא צורך בהתקנה מראש באמצעות `npx -y apple-hig-mcp`).

משמעות הדבר היא ש**אין צורך להוריד ידנית קבצים או לקמפל דבר**. כל סביבת פיתוח עם Node.js (גרסה 18 ומעלה) מושכת ומפעילה את השרת באופן מיידי.

---

## 2. מנגנון הגילוי ב-3 רמות (Discovery Hierarchy)

כאשר מפתח או סוכן AI נכנסים לפרויקט חדש, המערכת מאתרת ומושכת את ה-MCP לפי סדר עדיפויות קבוע:

```
┌────────────────────────────────────────────────────────┐
│ 1. בדיקת קיום בינארי גלובלי במערכת (PATH)               │
│    האם apple-hig-mcp כבר מותקן גלובלית ב-PATH?         │
│    (לדוגמה: /opt/homebrew/bin/apple-hig-mcp)           │
└──────────────────────────┬─────────────────────────────┘
                           │ אם לא קיים:
┌──────────────────────────▼─────────────────────────────┐
│ 2. משיכה דינמית לפי דרישה דרך npx (אפס התקנה מוקדמת)     │
│    הרצה מיידית: npx -y apple-hig-mcp                  │
│    מושך ישירות מ-npm ושומר במטמון הגלובלי               │
└──────────────────────────┬─────────────────────────────┘
                           │ אם עובדים בסביבה מבודדת/אופליין:
┌──────────────────────────▼─────────────────────────────┐
│ 3. תלות פיתוח מקומית בפרויקט (Local DevDependency)      │
│    npm install -D apple-hig-mcp                        │
│    npx apple-hig-mcp                                   │
└────────────────────────────────────────────────────────┘
```

## 3. סקריפט אוטונומי לבדיקה והגדרה בלחיצה אחת

התבנית כוללת סקריפט אבחון והגדרה אוטומטי מלא:
```bash
node design-system/scripts/setup-mcp.js
```

### מה הסקריפט מבצע בפועל?
1. בודק האם `apple-hig-mcp` מותקן כבר ב-PATH של המחשב.
2. מייצר אוטומטית קובץ `.mcp.json` בשורש הפרויקט.
3. מייצר אוטומטית קובץ `.cursor/mcp.json` עבור משתמשי Cursor IDE.
4. בודק חיבורים קיימים ב-**Google Antigravity**, ב-**Claude Code** וב-**Claude Desktop**.
5. מאמת את יכולת ההרצה ופולט הנחיות מדויקות.

---

## 4. הגדרה לפי סביבות פיתוח וסוכני AI

### א. Google Antigravity
פרויקט חדש שייפתח ב-Antigravity יזהה אוטומטית את קובץ ה-`.mcp.json` שבשורש הפרויקט.  
אם רוצים להגדיר אותו גלובלית עבור כל הפרויקטים ב-CLI:
```bash
agy mcp add apple-hig -- npx -y apple-hig-mcp
```

### ב. סביבת Cursor IDE
סביבת Cursor קוראת אוטומטית את הקובץ `.cursor/mcp.json` (שנוצר על ידי הסקריפט).  
לאחר ההרצה, תחת **Cursor Settings -> Features -> MCP**, יופיע השרת `apple-hig` עם חיווי ירוק פעיל.

### ג. סביבת Claude Code CLI
בטרמינל של הפרויקט מריצים:
```bash
claude mcp add apple-hig npx -y apple-hig-mcp
```

### ד. סביבת Claude Desktop
מוסיפים את השרת לקובץ ההגדרות:
- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`
```json
{
  "mcpServers": {
    "apple-hig": {
      "command": "npx",
      "args": ["-y", "apple-hig-mcp"]
    }
  }
}
```
