# RFC 002: מפרט ארכיטקטורה וחוזי רכיבים עבור חבילת 8 המעבדות

- **סטטוס**: אושר ומיושם (גרסה v0.3.0)
- **מחבר**: Code & AI Explorer Team (`team@learnai.internal`)
- **תאריך**: אוקטובר 2026
- **הרחבה ל**: RFC 001

---

## 1. רקע ומטרות

פלטפורמת ZenLab הורחבה מ-4 מעבדות בסיס לחבילה מקיפה של **8 מעבדות אינטראקטיביות**, במטרה לתת מענה מושלם לדרישות משרד החינוך בישראל לכיתות ה' ולסטנדרט הבינלאומי AI4K12.

מסמך זה מגדיר את חוזי הרכיבים (Component Contracts), המנועים המתמטיים והחישוביים, ומבנה הנתונים של 8 המעבדות.

## 3. חוזי הרכיבים החדשים

כל קומפוננטת מעבדה מממשת את הממשק הסטנדרטי:
```typescript
interface LabProps {
  curriculum: CurriculumData;
}
```

וכוללת:
1. **שלב תיאוריה (`TheoryView`):**
   - כרטיסי הסבר ממוקדים, אנלוגיה מהחיים, אנימציית SVG אינטראקטיבית, ונגן ליווי קולי מסונתז.
2. **שלב מעשי (`InteractiveView`):**
   - ארגז חול למניפולציה ישירה (ללא חסמי סינטקס טקסטואליים).
   - 3 אתגרים מדורגים המעניקים 3 כוכבים ומפעילים אפקט קונפטי וצלילי הצלחה.
   - מילון מושגים מובנה.
