## 🎯 Educational Mission

Traditional elementary computer science education often forces 10-year-olds into two extremes:
1. **Abstract Code Block Fatigue**: Repeating syntax puzzles without understanding the hardware or mathematical mechanics underneath.
2. **"Black-Box" Generative AI Consumerism**: Prompting closed cloud tools without any grasp of how weights, tokens, matrices, or decision trees actually compute answers.

**ZenLab bridges this divide.** By providing transparent, tactile, real-time manipulable simulations, 5th-grade learners physically interact with the fundamental mathematical building blocks:
- Flipping individual bits to generate ASCII, RGB, and hexadecimal codes.
- Stepping through a CPU pipeline and seeing the instruction register and accumulator update.
- Splitting animal feature sets to visualize entropy and decision tree purity.
- Running breadth-first vs. heuristic $A^*$ graph search to understand how Waze navigates obstacles.
- Placing fruits in a 2D feature space to watch k-Nearest Neighbor (k-NN) classification in real time.
- Sliding a $3 \times 3$ convolution filter across pixels to see edge detection live.
- Adjusting synapse weights and threshold bias to witness how an artificial neuron fires.
- Dialing the temperature gauge from $0.0$ to $1.5$ to see next-token Softmax probabilities transform.

## 🔒 Privacy & Classroom Safety
ZenLab operates with **Strict Zero-PII**:
- No accounts, no logins, no student personal data collection.
- 100% offline browser storage (`localStorage`).
- Zero server dependencies.
