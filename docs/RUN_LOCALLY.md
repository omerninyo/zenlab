# מדריך הרצה מקומית ובדיקות (Local Development & Testing Guide)

מסמך זה מפרט את אופן ההתקנה, ההרצה והאימות של פלטפורמת **ZenLab** בסביבת פיתוח מקומית.

---

## 1. דרישות מערכת מקדימות (Prerequisites)

- **Node.js**: גרסה `18.0.0` ומעלה (מומלץ LTS 20+)
- **מנהל חבילות (Package Manager)**: `npm` (גרסה 9 ומעלה) או `pnpm`
- **דפדפן מודרני**: Chrome, Edge, Safari או Firefox עם תמיכה ב-Web Audio API ו-Web Speech API

לבדיקת הגרסאות המותקנות במחשבך:
```bash
node -v
npm -v
```

---

## 2. התקנה ראשונית (Setup & Installation)

אם טרם שיכפלת את המאגר או התקנת את התלויות:

```bash
# 1. שיבוט המאגר (במידת הצורך)
git clone https://github.com/omerninyo/zenlab.git
cd zenlab

# 2. התקנת כלל החבילות הנדרשות
npm install
```

---

## 3. אפשרויות הרצה מקומית (Running Locally)

### אפשרות א': שרת פיתוח חי (Development Server)
מומלץ בעת עבודה על קוד, עריכת רכיבים ועדכון תכנים. השרת כולל מנגנון טעינה חמה (Hot Module Replacement) המעדכן את הדפדפן מיידית בכל שמירת קובץ.

```bash
npm run dev
```

- **כתובת ברירת מחדל**: [http://localhost:3000](http://localhost:3000)
- **יציאה/סיום ההרצה**: הקש `Ctrl + C` במסוף.

---

### אפשרות ב': תצוגה מקדימה של גרסת הייצור (Production Preview)
מומלץ לפני דחיפת קוד (Push) או פריסה, על מנת לבדוק את ה-Bundle המהודר, קובצי ה-Minification וביצועי הגרסה הסופית כפי שתרוץ ברשת (למשל ב-Cloudflare Pages).

```bash
# שלב 1: הידור ובניית קובצי הפרודקשן לספריית dist/
npm run build

# שלב 2: הפעלת שרת תצוגה מקדימה מקומי
npm run preview
```

- **כתובת ברירת מחדל**: [http://localhost:4173](http://localhost:4173)
- שרת זה מגיש את הקבצים המהודרים מתוך ספריית `dist/`.

## 4. צ'ק-ליסט בדיקות ואימות תקינות (Verification Checklist)

בעת בדיקת האפליקציה בדפדפן המקומי, מומלץ לבצע את הבדיקות הבאות:

| אזור בדיקה | בדיקה נדרשת | תוצאה מצופה |
| :--- | :--- | :--- |
| **כיווניות (RTL)** | פריסת הממשק, כותרות, תפריטים ותוויות | כל הטקסטים והרכיבים מיושרים לימין כהלכה (Right-to-Left). |
| **מעבר שלבים במעבדות** | לחיצה על `שלב 1: הבנה תיאורטית ומדיה` ו-`שלב 2: התנסות אינטראקטיבית` | מעבר חלק בין התצוגות, תוך שימור בחירת השלב במעבר בין מעבדות שונות. |
| **הדמיות עקרון אינטראקטיביות** | הפעלת ה-SVG בכל מעבדה (ביטים, מבוך רובוט, סיווג $k$-NN, עקומת Softmax) | אנימציות חלקות ושינוי ערכים דינמי בהקלקה/גרירה. |
| **משוב קולי ואפקטים** | לחיצה על מתג הסאונד (אייקון רמקול) וביצוע פעולות במעבדות | הפקת צלילים פרוצדורליים נקיים ללא שגיאות Web Audio. |
| **ליווי קולי (הקראה)** | לחיצה על כפתור `הסבר קולי` או `השמע הסבר` | הקראה קולית ברורה בעברית תקנית או חיווי התקדמות מונפש. |
| **אתגרי למידה וכוכבים** | ביצוע משימות בכל מעבדה (למשל ציור לב בפיקסלים, הרצת רובוט) | צבירת כוכבים, אנימציית קונפטי, ושימור ההתקדמות ב-`localStorage`. |
| **יומן מסוף (Console)** | פתיחת כלי המפתחים (F12 או Option+Cmd+I) | `0 Console Errors` – אפס שגיאות הרצה אדומות בקונסול. |
| **רספונסיביות מובייל** | מעבר לתצוגת סמארטפון (390px רוחב) | גלילה אופקית נוחה של טאבים, סקלביליות של כרטיסים ללא גלישה אופקית שבורה. |

## 5. פתרון תקלות נפוצות (Troubleshooting)

### פורט תפוס (Port in use)
אם פורט `3000` או `4173` תפוס על ידי תהליך אחר, ניתן להריץ עם פורט חלופי:
```bash
# הרצת שרת פיתוח בפורט מותאם אישית:
npx vite --port 3005

# הרצת שרת תצוגה מקדימה בפורט מותאם אישית:
npx vite preview --port 4180
```

### איפוס התקדמות ו-LocalStorage
אם ברצונך לאפס את כל הכוכבים והאתגרים שנצברו לבדיקה נקייה מאפס:
1. הקלק על כפתור **איפוס התקדמות** (אייקון חץ מעגלי) בסרגל העליון, או
2. הפעל בקונסול הדפדפן:
```javascript
localStorage.clear();
location.reload();
```

### חסימת שמע אוטומטי בדפדפן (Audio Autoplay Policy)
דפדפנים מודרניים חוסמים השמעת אודיו לפני אינטראקציה ראשונית של המשתמש. אם אינך שומע צלילים, הקלק תחילה במקום כלשהו במסך כדי לאפשר את הפעלת ה-`AudioContext`.

```bash
npm run build    # הידור מלא ובניית חבילת הפרודקשן (dist/)
npm run preview  # שרת תצוגה מקדימה של גרסת הפרודקשן (Vite preview)
```
