# Security & Privacy Policy

## Our Zero-PII Privacy Commitment

**ZenLab is engineered from the ground up to protect student and classroom privacy.**

Because our platform is designed for elementary school students (Grade 5, ages 10–11):
- **Zero Telemetry**: We do NOT track, collect, log, or profile student behavior.
- **Zero Server-Side Storage**: No student accounts, passwords, or personal profiles are stored on any server.
- **Client-Side Isolation**: All learning progress, earned stars, and completion state reside exclusively in the student's browser `window.localStorage`.
- **Zero Third-Party Trackers**: We use zero analytics beacons, third-party cookies, or advertising trackers.

## Reporting a Security Vulnerability or PII Issue

If you discover a security vulnerability, privacy leak, or accidental PII exposure in the codebase or public deployment, please report it immediately:

1. **Email**: Send details directly to `team@learnai.internal`.
2. **Details to Include**:
   - Description of the vulnerability or data exposure.
   - Steps to reproduce.
   - Potential impact on students or educators.
3. **Response Time**: We acknowledge security reports within 48 hours and aim to release a verified fix within 5 business days.

Please do not disclose security issues publicly via GitHub Issues before they have been resolved.
