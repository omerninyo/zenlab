# ZenLab: מעבדת מדעי המחשב והבינה המלאכותית האינטראקטיבית

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Build Status](https://img.shields.io/badge/build-passing-brightgreen.svg)]()
[![Platform](https://img.shields.io/badge/platform-Cloudflare%20Pages-orange.svg)]()

> **English Version**: For the English documentation, see [**`README.md`**](README.md).

**ZenLab** היא פלטפורמת למידה אינטראקטיבית בקוד פתוח, הפועלת כולה בצד הלקוח בדפדפן (Client-Side SPA), ומיועדת להקניית מושגי יסוד בחשיבה מחשובית, אלגוריתמיקה ובינה מלאכותית לתלמידי בית ספר יסודי (דגש על כיתות ה', גילאי 10–11).

הפלטפורמה פועלת 100% בדפדפן ללא צורך בשרת אחורי (Zero Backend), עם תמיכה מלאה וטבעית בכיווניות מימין לשמאל (RTL), אפס איסוף מידע אישי (Strict Zero-PII), וליווי קולי מסונתז מובנה.

## חבילת 8 המעבדות (The Eight-Lab Master Suite)

תוכנית הלימודים מחולקת לשני מסלולי ליבה מקבילים התואמים את מחוון משרד החינוך ומסגרת AI4K12 הבינלאומית:

### מסלול 1: חשיבה מחשובית ואלגוריתמיקה
1. **מעבדה 1: פיקסלים וביטים (`Lab1_BinaryPixels`)**:
   - **עקרון מרכזי:** ייצוג מידע דיגיטלי, ביטים, בייטים והמרה לבסיס 16 (Hexadecimal).
   - **מאפיינים:** רשת 8x8 אינטראקטיבית, זרימת 64 ביט בזמן אמת, תבניות גרפיות (לב, סמיילי, חרב) ואתגר קידוד אות ראשונה.
2. **מעבדה 2: רובוט אלגוריתמי (`Lab2_AlgorithmicRobot`)**:
   - **עקרון מרכזי:** רצף אלגוריתמי מדויק, תנאי קדם, וניפוי שגיאות לוגיות (Debugging).
   - **מאפיינים:** מבוך 6x6, תור פקודות ויזואלי (צעד, פנה שמאלה, פנה ימינה, אסוף מפתח, פתח שער), דיבגר צעד-אחר-צעד וחיווי מלכודות.
3. **מעבדה 3: עץ החלטות בלשי (`Lab3_DecisionTree`)**:
   - **עקרון מרכזי:** הסתעפויות תנאי מקוננות (`if-else`), חלוקת תכונות ומדידת טוהר קבוצות (Information Purity).
   - **מאפיינים:** בונה עצים אינטראקטיבי, שאלות פיצול (מעופף, בעל פרווה, 4 רגליים), מד טוהר בזמן אמת, ומעקב חיה בודדת בענפי העץ.
4. **מעבדה 4: מבוך החיפוש והמסלול הקצר (`Lab4_Pathfinder`)**:
   - **עקרון מרכזי:** ייצוג גרפים, מרחב מצבים, ואלגוריתמי ניווט חכמים (BFS מול A* Heuristic).
   - **מאפיינים:** מבוך 8x8, הצבת מחסומים, הדגמת סריקת רוחב שווה מול חיפוש מכוון יעד, והשוואת מספר הצעדים שנבדקו.

### מסלול 2: תפיסה, למידת מכונה ובינה מלאכותית
5. **מעבדה 5: מסווג למידת מכונה (`Lab5_MachineLearningClassifier`)**:
   - **עקרון מרכזי:** סיווג מונחה במרחב תכונות דו-ממדי (משקל מול גודל), אלגוריתם k השכנים הקרובים (k-NN) וגבולות החלטה.
   - **מאפיינים:** הוספת נקודות אימון בקליק, נקודת בדיקה ניתנת לגרירה, חישוב רדיוס אוקלידי, וכוונון פרמטר $k$.
6. **מעבדה 6: סטודיו פילטרים וראייה ממוחשבת (`Lab6_VisionKernels`)**:
   - **עקרון מרכזי:** כיצד בינה מלאכותית רואה ומזהה צורות באמצעות קונבולוציה דו-ממדית עם גרעין $3 \times 3$.
   - **מאפיינים:** ציור חופשי ותבניות (פסים, ריבוע, צלב), פילטרים לזיהוי קצוות (סובל אנכי/אופקי), חידוד וטשטוש, ומפרק חישוב פיקסל בודד.
7. **מעבדה 7: מתג הנוירון המלאכותי (`Lab7_Perceptron`)**:
   - **עקרון מרכזי:** הנוירון הבודד (פרספטרון), משקולות קלט, סף הטיה (Bias), הפרדה ליניארית ושערים לוגיים.
   - **מאפיינים:** סליידרים ל-$w_1, w_2, b$, קו החלטה דינמי על מישור היחידה, אימון שער AND ו-OR, והמחשה גיאומטרית של מגבלת שער ה-XOR.
8. **מעבדה 8: מודל שפה וחיזוי מילים (`Lab8_LanguageModelPredictor`)**:
   - **עקרון מרכזי:** טוקניזציה, חיזוי המילה הבאה במודלי שפה (LLMs), עקומת הסתברות Softmax וסליידר טמפרטורה.
   - **מאפיינים:** פרומפטים חינוכיים, מחוון טמפרטורה (0.0 דטרמיניסטי עד 1.5 יצירתי), דיאגרמת מקלות הסתברותית ומחולל מילים אוטורגרסיבי.

## תכונות מרכזיות למערכת החינוך בישראל

* **מבנה למידה היברידי דו-שלבי:** כל מעבדה כוללת שלב תיאוריה (`TheoryView`) עם כרטיסי מושג, אנימציית SVG אינטראקטיבית ונגן ליווי קולי, ושלב מעשי (`InteractiveView`) בארגז חול חי.
* **תעודת הצטיינות אינטראקטיבית:** מנגנון גמר המאפשר לתלמיד להזין את שמו מקומית, לצפות בדרגה ובכוכבים שצבר (עד 24 כוכבים), ולהדפיס תעודה מהודרת ישירות מהדפדפן.
* **אפס איסוף מידע (Strict Zero-PII):** התאמה מלאה לנהלי אבטחת מידע ופרטיות של משרד החינוך לתלמידי יסודי. אין צורך בהרשמה, אין עוגיות פולשניות, וכל המידע נשמר אך ורק ב-LocalStorage המקומי של המכשיר.
* **סינתזת שמע עצמאית (Web Audio API):** צלילי משוב, חיווי הצלחה ומנגינות ללא תלות בקבצי MP3 חיצוניים כבדים.
* **סרגל סינון מסלולים:** אפשרות סינון מהירה בין מסלול אלגוריתמיקה למסלול בינה מלאכותית למניעת הצפה קוגניטיבית אצל ילדים.

## הפעלה מקומית ופיתוח

### דרישות קדם
- Node.js גרסה 18 ומעלה
- npm גרסה 9 ומעלה

### פקודות הפעלה
```bash
# שכפול המאגר
git clone https://github.com/omerninyo/zenlab.git
cd zenlab

# התקנת תלויות
npm install

# הפעלת שרת פיתוח מקומי
npm run dev

# בניית גרסת ייצור (Production Build)
npm run build

# הרצת תצוגה מקדימה לגרסת הייצור
npm run preview
```

> **מדריך מפורט**: למדריך שלב-אחר-שלב בעברית כולל צילומי מסך ופתרון בעיות, עיינו ב-[**`docs/RUN_LOCALLY.md`**](docs/RUN_LOCALLY.md).

## פריסה ב-Cloudflare Pages

הפרויקט מותאם לפריסה ישירה ואופטימלית ב-Cloudflare Pages כיישום SPA מלא:
1. **ניתוב SPA מובנה:** קובץ [`public/_redirects`](public/_redirects) הכולל `/* /index.html 200` למניעת שגיאות 404 בעת רענון דף.
2. **הגדרות פריסה:**
   - Framework preset: `Vite`
   - Build command: `npm run build`
   - Output directory: `dist`
3. **תהליך CI/CD אוטומטי:** קובץ תצורה מלא ב-[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

### פריסה ידנית באמצעות Wrangler CLI
```bash
npx wrangler pages deploy dist --project-name=zenlab
```
